**`ESP32-C3-WROOM-02-N4`**（位号 U1，图题「ESP32-C3-智能家居被控端」）

### 2.2 固定外设映射与交换矩阵

**固定映射**
- UART0：U0TXD=GPIO21(12 脚) / U0RXD=GPIO20(11 脚)
- USB：USB_D−=GPIO18(13 脚) / USB_D+=GPIO19(14 脚)
- SPI2：FSPIQ=GPIO2 / FSPIHD=GPIO4 / FSPIWP=GPIO5 / FSPICLK=GPIO6 / FSPID=GPIO7 / FSPICS0=GPIO10
- JTAG：MTMS=GPIO4 / MTDI=GPIO5 / MTCK=GPIO6 / MTDO=GPIO7
- ADC1_CH0~CH4 = GPIO0~GPIO4（**工厂校准**）；ADC2_CH0 = GPIO5（**未校准，部分芯片版本不可用**）
- XTAL_32K_P=GPIO0 / XTAL_32K_N=GPIO1
- SPI0/1 与 GPIO12~GPIO17 复用，但**模组未引出**

**可经 GPIO 交换矩阵映射到任意 GPIO**（无固定引脚）
I2C（1 个，100/400Kbit/s，最高 800Kbit/s）、I2S（1 个）、LED PWM（6 路）、**RMT（双发双收）**、TWAI（ISO 11898-1 / CAN 2.0，1Kbit/s~1Mbit/s）、UART1

> 表 3-1 未列 GPIO8/GPIO9 的 ADC/SPI/JTAG 复用，AI 明确拒绝猜测，指向《ESP32-C3 技术参考手册》的 IO MUX 与 GPIO 交换矩阵章节。

## 3. 电源树

```
USB Type-C (16P) ──VBUS──> 5V ──┬──> AMS1117-3.3 (U2) ──> 3.3V ──> ESP32-C3 + 逻辑
                                │      (SOT-223, TAB→VOUT/3V3)
                                └──> D1 (SS14) ──> VDD ≈4.3V ──> 5×WS2812B
```

| 节点 | 位号 | 值 | 备注 |
|---|---|---|---|
| 5V 输入去耦 | C1 | 100nF | — |
| 5V 输入储能 | C5 | 10µF | 长导线输入时可改 22µF / 47µF |
| 5V 大容量储能 | **C15** | **1000µF 电解** | 接在 **D1 之前**的 5V 上；走线 ≥40mil；**耐压建议 ≥10V（未确认）** |
| 3.3V 输出储能 | C7 | 10µF | — |
| 3.3V 输出去耦 | C2 | 100nF | — |
| MCU 就近去耦 | C4 / C8 | 100nF / 10µF | U1 Pin1 旁 |
| EN RC 延迟 | R3 / C3 | 10k / 1µF | 原为 1k，已改 |
| WS2812B 降压 | **D1 = SS14** | 肖特基 | 5V → 约 4.3V |

**电平匹配原理（本设计最巧的一手）**
WS2812B 的 VIH = 0.7 × VDD。若 VDD=5V → VIH=3.5V，ESP32 的 3.3V 高电平不达标 → 闪烁/错色/不亮。
串 D1 后 VDD≈4.3V → VIH = 0.7 × 4.3 = **3.01V** < 3.3V，直接匹配，**省掉电平转换芯片**。

**AMS1117 热风险（记录中反复警告）**
5V→3.3V，压差 1.7V；300mA 时 P = 1.7 × 0.3 = **0.51W**，SOT-223 热阻约 60–100°C/W → 升温 30–50°C，TAB + VOUT 焊盘需大面积铺 3.3V 铜并打过孔。
若输入改 12V：压差 8.7V、300mA 时 2.6W，**会瞬间烧毁**，必须先用 MP1584 / MP2315 / LM2596 降到 5V —— 本方案未采用。

## 4. WS2812B 链路（LED3 ~ LED7，WS2812B-V6）

```
ESP32 IO4 ──> R7 (330Ω) ──┬──> D2 (SRV05-4 Pin1)
                          │
                          └──> LED3 DIN ──DOUT──> LED4 ──> LED5 ──> LED6 ──> LED7
```

| 位号 | 值/型号 | 作用 |
|---|---|---|
| LED3–LED7 | WS2812B-V6 ×5 | 72° 均布圆盘；引脚 VDD(1)/DOUT(2)/VSS(3)/DIN(4) |
| R7 | 330Ω | 数据线串阻，限制流过 ESD 管的瞬时电流 |
| R8 | 10kΩ | IO4 下拉，**防上电乱闪**（GPIO 初始化前为高阻） |
| D2 | **SRV05-4** | 数据线 ESD，0.6pF / ±15kV / SOT-23-6 / 立创 C21713978 / ¥0.58 |
| C10–C14 | 100nF ×5 | 每颗灯珠 VDD–VSS 去耦，**紧贴灯珠（≤2mm）** |

**WS2812B 电气事实**：典型 5V（3.5–5.5V）；单线归零码 **800kHz**，时序严格；单颗全白约 60mA（20mA×3），5 颗最大 300mA，整板约 500mA。

**D2 = SRV05-4 接法（AI 最终定稿）**

| SRV05-4 脚 | 接到 |
|---|---|
| Pin 1 (I/O1) | 数据线（R7 输出端，与 LED3 DIN 同节点） |
| Pin 5 (VCC) | **3.3V**（绝不能接 5V，否则把数据线钳到 5V 会打坏 ESP32） |
| Pin 2 (GND) | GND |
| Pin 3 / 4 / 6 | 悬空（原理图上打 ×） |

> ⚠️ AI 在推理过程中一度怀疑 Pin4 是 GND，最终按上表定稿，并注明 **不同厂商可能互换 I/O 脚位，务必比对实购型号的数据手册**。

**为什么换掉原来的 D2 = BZT52C3V3 齐纳**
3.3V 齐纳寄生电容 **100–450pF**（同系列 BZX84 在 3.3V 时达 450pF），而数据率 800kHz，并联在数据线上相当于低通滤波 → 闪烁/错色/不亮。齐纳特性还"软"，2.4V 就开始漏电。
曾被考虑但否决：PESD3V3L1BA（70pF 偏大）。备选未采用：D1213A-01LP-7B（C526497）、PESD4V0Z1BSFYL（C552547，¥0.13）。

## 5. 接口与按键

### 5.1 USB Type-C 母座（16P，`LAIL-TYPE-C-16PIN-08-WT`，USB 2.0）

| 引脚 | 接法 |
|---|---|
| VBUS（A4B9 / B4A9） | → 5V；靠座子加 10µF + 100nF |
| GND（A1B12 / B1A12） | → GND |
| **CC1（A5）/ CC2（B5）** | **各接一个独立 5.1kΩ 下拉到 GND** —— 不接则 C-to-C 线不给电 |
| DP1（A6）+ DP2（B6） | 并联 → **IO19（USB_D+，模组 14 脚）** |
| DN1（A7）+ DN2（B7） | 并联 → **IO18（USB_D−，模组 13 脚）** |
| SBU1 / SBU2（A8 / B8） | 悬空 NC |
| SHELL（13/14/15/16） | → GND，焊盘多打过孔 |

### 5.2 按键

| 位号 | 型号 | 功能 | 消抖 |
|---|---|---|---|
| SW1 | TS-1088-AR02016 | 把 **IO9** 拉地 = 下载键（BOOT） | C9 100nF |
| SW2 | — | 把 **EN** 拉地 = 复位键 | C6 100nF |

**手动进下载模式**：按住 SW1(IO9) → 点一下 SW2(EN) 并松开 → 再松开 SW1。

### 5.3 指示灯

| 位号 | 接法 | 说明 |
|---|---|---|
| LED1 | 3V3 → R1(1k) → 阳极 → 阴极 → GND | 常亮电源灯，约 1.5mA |
| LED2 | **IO3** → R2(1k) → 阳极 → 阴极 → GND | 高电平点亮（`digitalWrite(IO3, HIGH)`） |

### 5.4 UART0（保留）

TX=GPIO21（模组 12 脚）、RX=GPIO20（模组 11 脚），已引出。保留它的三个理由：

1. **救砖通道**：USB 挂掉或 IO18/IO19 被误配为普通 IO 时的保底（USB-TTL 的 RXD→板 TXD、TXD→板 RXD、GND 共地，按住 SW1 复位强制烧录）
2. **ROM Bootloader 启动日志**：发生在 USB 初始化之前，USB 看不到
3. **与外部 MCU / 串口传感器通信**（STM32、Arduino、语音/指纹/PM2.5 模块）

⚠️ TX/RX 为 3.3V 电平，外接 USB-TTL 跳线必须 3.3V，**5V 会击穿芯片**。
AI 提醒：**切勿把 Type-C 的 D+/D− 接到 UART 的 TX/RX 上**。

## 8. 硬件层面仍未完成

**PCB 未画**。圆盘的硬性布局要求：
- 模组顶部**天线区绝对净空**（禁铺铜、禁走线、禁放元件，含灯珠和电容）→ 建议天线朝外或让开圆盘中心
- 灯珠 VDD/GND 走线 **≥20mil (0.5mm)**，可内外各走一圈环形线，避免末端灯珠偏暗
- 数据线沿圆盘边缘走弧线/菊花链，**禁直角锐角**
- C10–C14 距灯珠引脚 ≤2mm；C15 走线 ≥40mil，靠 5V 输入口
- 5 颗灯珠按 **72°** 均布
- ESP32-C3 底部 EP 大面积接地 + 多打散热过孔；AMS1117 TAB 铺铜散热；D1 压降发热需铺铜
- DP/DN 尽量平行等长（USB 2.0 全速 12Mbps，<5cm 普通走线也能识别），远离晶振与天线；Type-C 座放板边
- C4/C8/C3/C6/C9 就近放置

**继电器 / 传感器 / 墙壁开关接口最终没做**（需求收窄成"只控制一组灯"）。记录中讨论过但搁置的方案：
继电器：GPIO→1kΩ→S8050 基极，发射极 GND，集电极接线圈，线圈反并 1N4148/1N4007 续流，线圈另一端 5V；220V 区与低压区间距 ≥3mm（最好开槽）。推荐 IO4/IO5/IO6/IO7。
MOSFET 调光：GPIO→100Ω→Gate（AO3400 / IRLZ44N），Gate-Source 并 10kΩ，Source→GND，Drain→LED 负极。
I2C（SHT30/BH1750）：IO0=SDA、IO1=SCL，各 4.7kΩ 上拉到 3.3V。
PIR/门磁：GPIO 与 GND 间 100nF 消抖。光敏：仅 ADC1（IO0/IO1/IO4），3.3V→光敏→GPIO→10kΩ 下拉→GND。墙壁开关：IO10 + 100nF + 10k 上拉。
GPIO 电流限制：**绝对最大 40mA，建议 20mA** —— 绝不可直驱继电器线圈或高亮 LED。

### 12.2 必须修改的两处

**① R8 = 10K 串联在 WS2812B 数据线上 —— 应为约 330Ω**

实测拓扑：`IO4 ─┬─ R8(10K) ── DIN 网络（→ D2 Pin1 → LED3 DIN）`
`└─ R7(10K) ── GND`（下拉，数值正确）

即：**串联电阻 R8 是 10K，不是 330Ω**（下拉 R7 的 10K 是对的，两者位号与预期互换了）。

为什么这是硬伤：
- R8 串联驱动的是灯珠的高阻 CMOS 输入，直流电平没问题，**但上升时间被 RC 拖慢**。
- 负载电容 ≈ 灯珠输入 + SRV05-4(0.6pF) + 走线 ≈ **10~20pF**，取 15pF：τ = 10K × 15pF = **150ns**。
- 数据线最终电平 3.3V，VIH ≈ 3.22V（见下条），上升到 VIH 需
  `t = τ·ln(3.3/(3.3−3.22)) = 3.72τ ≈ 558ns`。
- WS2812B 的 800kHz 协议里，**一个 "1" 位的高电平窗口只有 700ns**，判定门限约在 500~600ns。
  558ns 的爬升意味着高电平超过 VIH 只维持约 140ns → **"1" 会被判成 "0"**。
- 结果表现：完全不亮、或乱闪、或颜色错乱，且随温度/批次漂移。

换成 **330Ω**：τ = 330 × 15pF ≈ 5ns，爬升到 VIH 约 18ns，可忽略。33~100Ω 亦可。

**② D1 = SS14 是肖特基，压降只有约 0.4V，吃掉了电平匹配的余量**

原设计思路是用二极管把灯珠 VDD 压低，使 VIH = 0.7×VDD 降到 3.3V 以下。但原推导按**硅管 0.7V** 压降算：

| 器件 | Vf @300mA | VDD | VIH = 0.7×VDD | ESP32-C3 VOH≈3.3V 的余量 |
|---|---|---|---|---|
| **SS14（肖特基，现用）** | ≈ 0.35~0.4V | ≈ **4.6V** | **3.22V** | 仅 ≈ 80mV ⚠️ |
| 原推导假设（硅管） | 0.7V | 4.3V | 3.01V | 290mV |
| 推荐改用硅管 | ≈ 0.8~1.0V | ≈ 4.1V | ≈ 2.87V | ≈ 430mV ✓ |

**建议**：把 D1 从 SS14（肖特基）换成**硅二极管**，例如 1N4007 / M7 / ES1D / US1D（SMA 封装，1A），VDD 落到约 4.0~4.2V，VIH 降到约 2.8~2.9V。
WS2812B 的 VDD 规格是 3.5~5.5V，4.1V 完全在范围内。
（更稳妥的方案是在数据线上加 74AHCT1G125 之类的电平转换，但换一颗二极管成本最低。）

> ⚠️ 这两条是**叠加**的：即使不改二极管，10K 串阻本身就已经让数据传不过去；改完串阻后，SS14 的低压降又会把余量压到 80mV。**两条都要改。**

### 12.4 PCB 布局硬要求（圆盘）

- **模组天线区绝对净空**：禁铺铜、禁走线、禁放元件（含灯珠与电容）。圆盘板尤其危险 —— 建议天线朝板边外侧，或让开圆盘中心。
- 5 颗灯珠按 **72°** 均布；**数据链必须按 LED3→LED4→LED5→LED6→LED7 的物理顺序绕圆**，否则旋转/追逐类效果会错位。
- VDD / GND 走线 **≥20mil (0.5mm)**，建议内外各走一圈环形线，避免末端灯珠偏暗。
- 数据线走弧线，禁直角锐角；C10–C14 距各自灯珠引脚 ≤2mm。
- C4/C8 紧贴 U1 Pin1；C3 靠 EN 脚；C6/C9 靠按键。
- AMS1117 的 TAB + VOUT 大面积铺 3.3V 铜皮并打过孔（功耗约 0.51W）。
- U1 底部 EP 大面积接地 + 多打散热过孔；D1 也要铺铜散热。
- Type-C 座置板边；DP/DN 尽量平行等长，远离天线与晶振。

### 13.3 新发现：D1 的封装/3D 模型是 TVS，不是肖特基

3D 渲染里 D1 器体上印的是 **`SMAJ12A`**（12V TVS 二极管），说明这个封装是从 TVS 库里取的。

- **风险 1（严重）**：如果 BOM/贴片单里跟着写成了 `SMAJ12A`，贴上去的是一颗 12V TVS —— 它 5V 下完全不导通，**灯珠永远不亮**。务必确认实际器件是 SS14 或你要换的硅管。
- **风险 2**：SMAJ12A 的阴极带位置与 SS14 一致（都在带杠一端），但要确认**封装的丝印极性带方向**与 §12 里验证过的"阳极接 5V、阴极接 VDD"一致，否则二极管装反。

### 13.5 还需要在 PCB 上复核的两点

1. **数据链的物理顺序**：确认 LED3→LED4→LED5→LED6→LED7 是沿着灯带的实际排列顺序串起来的。如果顺序错开，旋转/彩虹追逐类效果会错位（功能能跑，但效果难看）。
2. **VDD/GND 到灯珠的走线宽度 ≥0.5mm (20mil)**：5 颗全白瞬时约 300mA，细线会压降导致末端灯珠偏暗。
